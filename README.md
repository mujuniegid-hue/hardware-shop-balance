# Mukasa Hardware Balance Checker

A simple Flask web tool for a Kampala hardware shop that sells on credit.
Type a customer's name and see how much they owe.

## Features

- Home page (`/`) with a search form
- JSON API (`/api/balance?name=Joseph`) that returns a customer's balance
- Customer balances stored in a Python dictionary (demo data)

## How to run

1. Create and activate a virtual environment
2. Install dependencies: `pip install -r requirements.txt`
3. Start the app: `python app.py`
4. Open http://127.0.0.1:5000
